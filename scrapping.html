Scrapping Data#

Scraping data adalah proses otomatis untuk mengambil informasi dari sumber digital, seperti halaman web, menggunakan program. Pada notebook ini, data artikel berita Detik.com dikumpulkan untuk dua kategori, yaitu sport dan finance, kemudian disiapkan untuk analisis teks dan klasifikasi.

Scraping data adalah teknik otomatisasi menggunakan bot atau skrip komputer untuk mengekstrak dan mengambil data spesifik dari berbagai sumber seperti halaman website, basis data, atau aplikasi lalu menyimpannya ke dalam format terstruktur seperti spreadsheet atau CSV.

Cara Kerja Scraping DataProses pengambilan data ini umumnya melalui tiga tahapan utama:

  • Request: Program mengirimkan permintaan (command) untuk mengakses halaman atau sumber data yang dituju.

  • Parse: Sistem membaca struktur kode (seperti HTML) atau antarmuka untuk mencari dan mengidentifikasi data spesifik yang diinginkan.

  • Display/Save: Data yang ditemukan diekstrak dan diubah menjadi format rapi seperti CSV, JSON, atau database agar mudah dianalisis.

Langkah 1: Mengumpulkan 200 URL Artikel Detik.com#

Tahap pertama adalah mengumpulkan alamat artikel dari halaman indeks Detik.com. Fungsi yang digunakan mengambil URL secara bertahap berdasarkan halaman indeks hingga memperoleh 100 artikel kategori sport dan 100 artikel kategori finance. Setiap URL disimpan bersama kategorinya sebagai label awal.

import requests
from bs4 import BeautifulSoup
import time
import pandas as pd

def get_detik_urls_by_category(base_url, target_count=100, category_name=""):
    urls = []
    page = 1
    
    print(f"Mengumpulkan URL untuk kategori: {category_name.upper()}...")
    while len(urls) < target_count:
        index_url = f"{base_url}?page={page}"
        headers = {"User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64)"}
        
        response = requests.get(index_url, headers=headers)
        if response.status_code != 200:
            print(f"Gagal mengakses halaman {page} untuk {category_name}")
            break
            
        soup = BeautifulSoup(response.text, 'html.parser')
        articles = soup.find_all('article')
        
        for article in articles:
            link = article.find('a')
            if link and 'href' in link.attrs:
                href = link['href']
                if "detik.com" in href and href not in [item['url'] for item in urls]:
                    urls.append({
                        'url': href,
                        'category': category_name
                    })
                    if len(urls) >= target_count:
                        break
                        
        print(f"Kategori {category_name} - Halaman {page}: Terkumpul {len(urls)} URL")
        page += 1
        time.sleep(1) # Jeda agar tidak diblokir server
        
    return urls[:target_count]

Langkah 2: Proses Scraping Menggunakan Trafilatura#

Pada tahap ini, setiap URL diakses untuk mengambil metadata dan isi berita. BeautifulSoup digunakan untuk membaca judul serta tanggal artikel, sedangkan trafilatura digunakan untuk memperoleh teks berita yang lebih bersih dari elemen HTML yang tidak diperlukan. Hasil setiap artikel disimpan sebagai satu baris data.

import trafilatura
import requests
from bs4 import BeautifulSoup
import pandas as pd
import time

data_hasil = []
total_data = len(all_target_urls)

print(f"Memulai scraping {total_data} data (Sport & Finance)...")
for idx, item in enumerate(all_target_urls):
    url = item['url']
    category = item['category']
    
    try:
        # 1. Ambil HTML mentah menggunakan requests untuk parsing judul & tanggal
        headers = {"User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64)"}
        resp = requests.get(url, headers=headers)
        
        title = None
        date = None
        if resp.status_code == 200:
            soup = BeautifulSoup(resp.text, 'html.parser')
            # Ambil judul dari tag <h1> atau <title>
            title_tag = soup.find('h1') or soup.find('title')
            if title_tag:
                title = title_tag.text.strip()
                
            # Ambil tanggal dari tag div class detail__date
            date_tag = soup.find('div', class_='detail__date')
            if date_tag:
                date = date_tag.text.strip()

        # 2. Ambil teks bersih menggunakan Trafilatura
        downloaded = trafilatura.fetch_url(url)
        text = ""
        if downloaded:
            extracted = trafilatura.extract(downloaded, include_comments=False, include_tables=False)
            if extracted:
                text = extracted
                
        # Simpan ke list of dictionary
        data_hasil.append({
            'url': url,
            'category': category, # Menyimpan label sport atau finance
            'title': title,
            'date': date,
            'text': text
        })
        
        print(f"Berhasil scrape [{idx+1}/{total_data}] - {category.upper()}")
    except Exception as e:
        print(f"Gagal pada URL {url}: {e}")
        
    time.sleep(0.5)

# 3. Buat DataFrame
df = pd.DataFrame(data_hasil)

# 4. Tambahkan kolom panjang karakter dengan perlindungan fillna('') agar terhindar dari TypeError
df['title_length'] = df['title'].fillna('').astype(str).apply(len)
df['text_length'] = df['text'].fillna('').astype(str).apply(len)

Cleaning Data#

Pembersihan data teks dilakukan untuk mengurangi noise yang dapat mengganggu analisis. Prosesnya meliputi pengubahan huruf menjadi huruf kecil (case folding), penghapusan URL, angka, tanda baca, stopword Bahasa Indonesia, serta kata yang terlalu pendek. Hasil pembersihan disimpan pada kolom clean_text.

from sklearn.feature_extraction.text import CountVectorizer
import re
import string

# Daftar stopword sederhana Bahasa Indonesia untuk menyaring kata tugas
stopwords_indonesia = set([
    'dan', 'yang', 'di', 'ke', 'dari', 'ini', 'itu', 'untuk',
    'pada', 'dengan', 'adakah', 'sebagai', 'oleh', 'karena',
    'bahwa', 'atau', 'dalam', 'mereka', 'nya', 'tersebut',
    'juga', 'akan', 'terhadap', 'secara', 'dapat', 'bagi',
    'sudah'
])

def advanced_preprocessing(text):
    if pd.isna(text):
        return ""

    # 1. Case Folding (Ubah ke huruf kecil semua)
    text = text.lower()
    # 2. Hapus tautan/URL
    text = re.sub(r'https?://\S+|www\.\S+', '', text)
    # 3. Hapus angka
    text = re.sub(r'\d+', '', text)
    # 4. Hapus tanda baca (titik, koma, tanda seru, dll)
    text = text.translate(str.maketrans('', '', string.punctuation))
    
    # Hapus stopword dan kata yang terlalu pendek (1-2 huruf)
    words = text.split()
    filtered_words = [w for w in words if w not in stopwords_indonesia and len(w) > 2]
    
    return " ".join(filtered_words)

# Terapkan ulang preprocessing yang lebih bersih
df['clean_text'] = df['text'].apply(advanced_preprocessing)

Ekstrak Kata Unik#

Teks yang telah dibersihkan perlu diubah menjadi fitur numerik agar dapat digunakan dalam analisis. Pada tahap ini, CountVectorizer menghitung kemunculan setiap kata pada seluruh dokumen. Parameter min_df=2 digunakan agar kata yang hanya muncul satu kali tidak dimasukkan sebagai fitur. Hasilnya adalah matriks Bag-of-Words dengan dokumen sebagai baris dan kata sebagai kolom.

from sklearn.feature_extraction.text import CountVectorizer
import pandas as pd

# 1. Inisialisasi CountVectorizer untuk mengekstrak seluruh kata unik
# min_df=2 artinya kata harus muncul minimal di 2 dokumen agar dicatat sebagai fitur
vectorizer = CountVectorizer(min_df=2)

# 2. Proses ekstraksi kata unik dari kolom 'clean_text'
X_count = vectorizer.fit_transform(df['clean_text'])
# 3. Ubah hasil sparse matrix menjadi Pandas DataFrame (kolom = kata unik, baris = dokumen)
df_bow = pd.DataFrame(X_count.toarray(), columns=vectorizer.get_feature_names_out())
# 4. Tambahkan kolom label sesuai permintaan (sport: 1, finance: 2)
df_bow['label'] = df['category'].map({'sport': 1, 'finance': 2})

print(f"Jumlah dokumen: {df_bow.shape[0]} baris")
print(f"Jumlah kata unik setelah difilter: {df_bow.shape[1] - 1} kata unik")

# Tampilkan beberapa kolom pertama dan kolom label terakhir dari matriks

Penerapan TF-IDF#

TF-IDF (Term Frequency-Inverse Document Frequency) digunakan untuk mengubah teks menjadi nilai numerik berdasarkan tingkat kepentingan setiap kata dalam suatu dokumen. Metode ini memberikan bobot tinggi pada kata yang sering muncul dalam satu dokumen, tetapi jarang ditemukan pada dokumen lain.

Nilai TF-IDF terdiri dari dua bagian utama:

  • Term Frequency (TF) mengukur seberapa sering sebuah kata muncul dalam satu dokumen.

  • Inverse Document Frequency (IDF) mengurangi bobot kata yang muncul pada banyak dokumen karena kata tersebut kurang mampu membedakan isi antar dokumen.

Secara umum, nilai TF-IDF dirumuskan sebagai:

\[ TFIDF(t,d) = TF(t,d) \times IDF(t) \]

Pada proses ini, TfidfVectorizer(min_df=2) digunakan untuk membentuk matriks TF-IDF dari kolom clean_text. Parameter min_df=2 berarti kata harus muncul minimal pada dua dokumen agar digunakan sebagai fitur. Hasil akhirnya berupa matriks numerik dengan baris sebagai dokumen dan kolom sebagai kata. Kolom label ditambahkan untuk merepresentasikan kategori berita, yaitu sport dengan label 1 dan finance dengan label 2.

from sklearn.feature_extraction.text import TfidfVectorizer
import pandas as pd

# 1. Inisialisasi TfidfVectorizer
# Kita menggunakan parameter min_df=2 yang sama seperti sebelumnya agar kata yang terlalu langka tersaring
tfidf_vectorizer = TfidfVectorizer(min_df=2)

# 2. Fit and transform teks yang sudah dibersihkan (clean_text)
X_tfidf = tfidf_vectorizer.fit_transform(df['clean_text'])

# 3. Ubah hasil matrix sparse TF-IDF menjadi Pandas DataFrame
df_tfidf = pd.DataFrame(X_tfidf.toarray(), columns=tfidf_vectorizer.get_feature_names_out())

# 4. Tambahkan kembali kolom label (sport: 1, finance: 2) di ujung DataFrame
df_tfidf['label'] = df['category'].map({'sport': 1, 'finance': 2})

print("Representasi TF-IDF berhasil dibuat!")
print(f"Ukuran Dataset TF-IDF: {df_tfidf.shape[0]} baris dokumen dan {df_tfidf.shape[1] - 1} kolom kata unik (+ 1 kolom label)")

Penerapan PCA#

PCA (Principal Component Analysis) merupakan metode reduksi dimensi yang digunakan untuk menyederhanakan fitur tanpa menghilangkan sebagian besar informasi penting. Setelah teks diubah menjadi fitur TF-IDF, jumlah kolom kata dapat menjadi sangat banyak sehingga PCA membantu membuat data lebih ringkas dan lebih mudah dianalisis.

PCA (Principal Component Analysis) adalah metode reduksi dimensi yang digunakan untuk mengurangi jumlah fitur tanpa menghilangkan sebagian besar informasi penting dari data. Pada hasil TF-IDF, jumlah kolom kata dapat sangat banyak sehingga analisis dan pemodelan menjadi lebih berat.

PCA mengubah fitur-fitur awal menjadi beberapa komponen utama yang saling tidak berkorelasi. Komponen pertama (PC1) menyimpan variasi terbesar dalam data, komponen kedua (PC2) menyimpan variasi terbesar berikutnya, dan begitu seterusnya. Jumlah informasi yang dipertahankan dapat dilihat melalui explained_variance_ratio_.

Pada notebook ini, PCA(n_components=100) digunakan untuk mereduksi fitur TF-IDF menjadi maksimal 100 komponen utama. Data hasil reduksi disimpan dalam df_pca, sedangkan kolom label tetap ditambahkan untuk mempertahankan kategori asli berita. Nilai total explained variance menunjukkan persentase informasi dari data TF-IDF yang masih dipertahankan setelah reduksi dimensi.

from sklearn.decomposition import PCA
import pandas as pd

# 1. Pisahkan antara Fitur (X) dan Label (y)
# X adalah matriks TF-IDF (semua kolom kecuali 'label')
X = df_tfidf.drop(columns=['label'])
# y adalah kolom label
y = df_tfidf['label']

# 2. Tentukan jumlah komponen PCA yang diinginkan
pca = PCA(n_components=100, random_state=42)

# 3. Lakukan fitting dan transform pada data TF-IDF
X_pca = pca.fit_transform(X)

# 4. Buat DataFrame baru hasil reduksi PCA
# Membuat nama kolom secara otomatis: PC1, PC2, dst.
pca_columns = [f'PC{i+1}' for i in range(X_pca.shape[1])]
df_pca = pd.DataFrame(X_pca, columns=pca_columns)

# 5. Masukkan kembali kolom label di ujung DataFrame
df_pca['label'] = y.values

print(f"Dimensi awal: {X.shape[1]} kolom fitur")
print(f"Dimensi setelah PCA: {df_pca.shape[1] - 1} komponen utama (+ 1 kolom label)")

# Menampilkan informasi total varians yang berhasil dipertahankan oleh komponen
explained_variance_sum = pca.explained_variance_ratio_.sum() * 100
print(f"Total informasi (varians) data asli yang dipertahankan: {explained_variance_sum:.2f}%")

# Tampilkan 5 baris pertama dari hasil PCA
display(df_pca.iloc[:, :6].assign(label=df_pca['label']).head())
display(df_pca.iloc[:, :6].assign(label=df_pca['label']).tail())
